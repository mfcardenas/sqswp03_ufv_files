Before submitting, verify:

### Content (Criteria A-D)
- [ ] Define usability according to ISO 9241-11 correctly
- [ ] Explain differences between effectiveness, efficiency, satisfaction with examples
- [ ] Identify at least 5 diverse user profiles
- [ ] Analyze tasks, equipment and environments for each main profile
- [ ] Include 3 detailed personas with ALL required information
- [ ] Personas are realistic, not stereotypes
- [ ] Narrative scenarios with concrete details (dates, places, budgets)
- [ ] Define 6-9 specific and measurable metrics per persona
- [ ] Justify metrics in relation to ISO 9241-11

### Process (Criterion C3)
- [ ] Document AI use with screenshots
- [ ] Show iterations, not just final result
- [ ] Reflect on AI strengths and limitations

### Format (Criterion E)
- [ ] Follow provided template
- [ ] 8-12 pages (without appendices)
- [ ] Font: Arial/Calibri 11-12pt, line spacing 1.5
- [ ] No spelling/grammatical errors
- [ ] Numbered tables and figures
- [ ] References in APA or IEEE format
- [ ] Well-generated PDF

### Reflection (Criterion F)
- [ ] Deep reflection section (not superficial)
- [ ] Connect theory (ISO 9241-11) with practice (TravelEase)
- [ ] Analyze process and learnings

## 🔄 Feedback and Continuous Improvement

### For the Student

After receiving your grade:
1. **Read complete feedback** - not just the numerical grade
2. **Identify patterns** - which criteria need improvement?
3. **Ask if you don't understand** - feedback should be clear
4. **Apply in Lab 2** - use learnings in next laboratory

### For the Instructor

After evaluating all reports:
1. **Identify common errors** - which criterion was most difficult for majority?
2. **Adjust following Labs** - reinforce misunderstood concepts
3. **Update materials** - if many failed at something, maybe explanation wasn't clear
4. **Share best practices** - show anonymous examples of excellent work
