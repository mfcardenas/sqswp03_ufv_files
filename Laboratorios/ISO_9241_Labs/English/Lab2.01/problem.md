# Lab 2: Usability Principles

## Problem Statement

You are required to analyze and improve a poorly designed web form that violates several ISO 9241 usability principles. The original form has issues with effectiveness, efficiency, and satisfaction.

### Requirements:
1. Identify usability violations in the provided code.
2. Redesign the form to comply with ISO 9241-11 principles.
3. Implement improvements in HTML, CSS, and JavaScript.
4. Create a Python script to compare the usability of the original and improved versions.
5. Document the changes and their impact on usability metrics.

### Tasks:
- Analyze the original form code for usability issues.
- Redesign the form with better layout, feedback, and accessibility.
- Add client-side validation and error handling.
- Write a Python script using Selenium to measure task completion times for both versions.
- Compare the results and explain improvements.

## Expected Output:
- Improved HTML, CSS, and JavaScript code.
- A Python testing script.
- Documentation of usability improvements.
