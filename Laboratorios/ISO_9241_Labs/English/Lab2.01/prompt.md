# Lab 2: Usability Principles

## Regeneration Prompt

Design a laboratory exercise that demonstrates usability principles from ISO 9241 by having students analyze and improve a poorly designed web form. Include:

1. A problem statement with a form that violates multiple usability principles.
2. A detailed solution showing the original problematic code and the improved version.
3. HTML, CSS, and JavaScript code for the improved form with proper validation and feedback.
4. A Python script using Selenium to measure and compare usability metrics between versions.
5. Documentation explaining how the improvements address effectiveness, efficiency, and satisfaction criteria.
6. Practical tasks for students to implement and test the changes.

Ensure the lab emphasizes real-world application of ISO 9241 standards with measurable outcomes.
