# Lab 3: Ergonomic Requirements

## Regeneration Prompt

Create a comprehensive laboratory exercise focusing on ergonomic requirements from ISO 9241-400 series. The lab should include:

1. A problem statement for designing an ergonomic text editor.
2. Complete HTML, CSS, and JavaScript code implementing ergonomic features.
3. Keyboard shortcuts, adjustable display settings, and fatigue prevention measures.
4. A Python script for analyzing user interaction patterns and ergonomics metrics.
5. Documentation explaining compliance with physical input device standards.
6. Practical implementation tasks with measurable ergonomic outcomes.

Ensure the lab provides hands-on experience with real ergonomic design principles and data-driven analysis.
