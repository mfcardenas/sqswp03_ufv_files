# Lab 3: Ergonomic Requirements

## Problem Statement

Design a web-based text editor that incorporates ergonomic principles from ISO 9241-400 series (Physical input devices). The editor should minimize strain and fatigue while maximizing productivity.

### Requirements:
1. Implement keyboard shortcuts for common actions.
2. Design an interface that reduces mouse usage.
3. Include adjustable font sizes and contrast settings.
4. Add features to prevent repetitive strain injuries.
5. Create a Python script to analyze user interaction patterns.
6. Ensure compliance with ergonomic guidelines for visual display units.

### Tasks:
- Create an HTML editor with ergonomic features.
- Implement keyboard navigation and shortcuts.
- Add customizable display settings.
- Write JavaScript for ergonomic interactions.
- Develop a Python script to log and analyze user behavior.
- Document ergonomic improvements and their benefits.

## Expected Output:
- A functional text editor with ergonomic features.
- Python analysis script.
- Documentation of ergonomic compliance.
