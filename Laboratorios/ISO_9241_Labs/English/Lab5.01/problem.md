# Lab 5: Accessibility Standards

## Problem Statement

Design and implement an accessible web application that complies with WCAG 2.1 guidelines and ISO 9241 accessibility requirements. The application should be usable by people with disabilities and provide an inclusive user experience.

### Requirements:
1. Implement WCAG 2.1 Level AA compliance.
2. Add support for screen readers and assistive technologies.
3. Ensure keyboard-only navigation.
4. Provide alternative text for all images and media.
5. Implement high contrast mode and adjustable text sizes.
6. Create a Python script to test accessibility compliance.

### Tasks:
- Design an accessible web page with proper semantic HTML.
- Implement ARIA attributes and roles.
- Add keyboard event handlers and focus management.
- Create CSS for high contrast and scalable text.
- Write JavaScript for dynamic accessibility features.
- Develop Python script using accessibility testing tools.

## Expected Output:
- WCAG compliant web page.
- Python accessibility testing script.
- Documentation of accessibility features.
