# Lab 6: Interaction Design

## Regeneration Prompt

Create a comprehensive laboratory exercise demonstrating advanced interaction design principles from ISO 9241-110. Include:

1. A problem statement for designing an interactive web application with gesture-based controls.
2. Complete HTML, CSS, and JavaScript code implementing drag-and-drop, gestures, and context-aware help.
3. Undo/redo functionality and consistent interaction patterns.
4. A Python script for analyzing user interaction patterns and usability metrics.
5. Documentation of dialogue principles and their implementation.

Ensure the lab provides hands-on experience with modern interaction design techniques and data-driven analysis.
