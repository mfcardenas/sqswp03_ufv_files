# Lab 1: Introduction to ISO 9241

## Problem Statement

You are tasked with creating a simple web application that demonstrates the basic principles of ISO 9241. The application should include a login form that adheres to usability guidelines from ISO 9241-11 (Guidance on usability).

### Requirements:
1. Design a login form with fields for username and password.
2. Ensure the form follows usability principles: effectiveness, efficiency, and satisfaction.
3. Include error handling for invalid inputs.
4. Provide feedback to the user after submission.
5. Write a Python script to simulate user interaction and evaluate the form's usability.

### Tasks:
- Create an HTML file for the login form.
- Add CSS for styling to improve visual ergonomics.
- Implement JavaScript for client-side validation.
- Write a Python script using Selenium to automate user testing and measure task completion time.

## Expected Output:
- A functional web page with a usable login form.
- A Python script that runs automated tests and reports usability metrics.
