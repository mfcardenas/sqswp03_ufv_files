# Lab 1: Introduction to ISO 9241

## Regeneration Prompt

Create a detailed laboratory exercise introducing ISO 9241 standards, focusing on usability principles. The lab should include:

1. A problem statement requiring the design of a simple web-based login form that adheres to ISO 9241-11 guidelines.
2. A comprehensive solution with HTML, CSS, and JavaScript code for the form, including error handling and user feedback.
3. A Python script using Selenium for automated usability testing, measuring task completion time and success rate.
4. Step-by-step instructions for implementation and evaluation.
5. Emphasis on the three main usability criteria: effectiveness, efficiency, and satisfaction.

Ensure the content is educational, practical, and includes code examples that students can run and modify.
