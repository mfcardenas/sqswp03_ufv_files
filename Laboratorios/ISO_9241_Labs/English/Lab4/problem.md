# Lab 4: User-Centered Design

## Problem Statement

Apply the user-centered design (UCD) process from ISO 9241-210 to redesign an existing e-commerce checkout form. The goal is to improve conversion rates and user satisfaction through iterative design and testing.

### Requirements:
1. Analyze the current checkout form for usability issues.
2. Create user personas and scenarios.
3. Design wireframes and prototypes.
4. Conduct usability testing.
5. Implement improvements based on user feedback.
6. Create a Python script to simulate user testing and analyze results.

### Tasks:
- Document current usability problems.
- Develop user personas and use cases.
- Create HTML/CSS/JS prototypes of improved design.
- Implement A/B testing functionality.
- Write Python scripts for automated user testing.
- Analyze and document improvements.

## Expected Output:
- User personas and scenarios.
- Multiple design iterations.
- Functional prototype with testing capabilities.
- Python analysis scripts.
