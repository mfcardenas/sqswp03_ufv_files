# Lab 4: User-Centered Design

## Regeneration Prompt

Create a comprehensive laboratory exercise demonstrating the user-centered design process from ISO 9241-210. Include:

1. A problem statement for redesigning an e-commerce checkout using UCD principles.
2. User personas, scenarios, and requirements analysis.
3. Complete HTML, CSS, and JavaScript code for a multi-step checkout form.
4. A Python script for automated user testing and usability evaluation.
5. Documentation of the UCD process and iterative improvements.
6. Practical implementation with measurable outcomes.

Ensure the lab provides hands-on experience with real UCD methodologies and data-driven design decisions.
