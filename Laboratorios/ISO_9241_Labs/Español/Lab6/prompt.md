# Laboratorio 6: Diseño de Interacción

## Prompt de Regeneración

Crear un ejercicio de laboratorio integral demostrando principios avanzados de diseño de interacción del ISO 9241-110. Incluir:

1. Un enunciado del problema para diseñar una aplicación web interactiva con controles basados en gestos.
2. Código completo HTML, CSS y JavaScript implementando arrastrar y soltar, gestos y ayuda sensible al contexto.
3. Funcionalidad de deshacer/rehacer y patrones de interacción consistentes.
4. Un script en Python para analizar patrones de interacción del usuario y métricas de usabilidad.
5. Documentación de principios de diálogo y su implementación.

Asegurar que el laboratorio proporcione experiencia práctica con técnicas modernas de diseño de interacción y análisis basado en datos.
