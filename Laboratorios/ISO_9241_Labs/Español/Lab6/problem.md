# Laboratorio 6: Diseño Centrado en Usuario - Proceso Iterativo Completo

## Enunciado del Problema

Aplicarás el proceso completo de Diseño Centrado en Usuario (HCD) según ISO 9241-210 para mejorar iterativamente la experiencia de TravelEase. Integrarás todo el trabajo de laboratorios previos (personas, principios, evaluaciones) en un ciclo de diseño-prototipo-evaluación-refinamiento hasta alcanzar métricas target de usabilidad. Demostrarás el valor del enfoque iterativo vs. diseño único.

### Objetivos:
1. Implementar proceso HCD completo siguiendo 6 principios de ISO 9241-210
2. Ejecutar 2-3 iteraciones de mejora basadas en hallazgos del Lab 5
3. Validar cada iteración con usuarios reales y métricas objetivas
4. Documentar trayectoria de mejora y learnings emergentes
5. Generar roadmap de implementación para organización real
6. Demostrar ROI del proceso iterativo con evidencia cuantificada

### Entregables:
- Plan de proceso HCD con cronograma de iteraciones
- 2-3 prototipos evolucionados con mejoras incrementales
- Evaluación de cada iteración con 5-6 usuarios por ciclo
- Análisis de progreso hacia métricas target (efectividad >85%, SUS >75)
- Reporte ejecutivo con business case para continuous UX improvement
- Framework replicable para otras organizaciones

## Metodología:
- Framework: ISO 9241-210:2019 (Human-centred design for interactive systems)
- Approach: Iterativo con cycles de 2-3 días por iteración
- Validation: Testing empírico en cada iteración + triangulación metodológica
- Focus: Integration de todo el trabajo previo en proceso holístico
- Output: Recommendations implementables con estimación de impacto y esfuerzo
