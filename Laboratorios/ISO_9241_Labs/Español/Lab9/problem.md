# Laboratorio 9: Estándares de Dispositivos de Entrada

## Enunciado del Problema

Diseñar e implementar herramientas para evaluar estándares de dispositivos de entrada según ISO 9241-410 (Criterios de Diseño para Dispositivos de Entrada Física) e ISO 9241-411 (Métodos de Evaluación para el Diseño de Dispositivos de Entrada Física). Crear aplicaciones que evalúen ergonomía de dispositivos de entrada, usabilidad y cumplimiento con estándares internacionales.

### Requisitos:
1. Implementar herramientas de evaluación ergonómica de dispositivos de entrada.
2. Crear sistemas de evaluación de usabilidad para diversos dispositivos de entrada.
3. Desarrollar verificación de cumplimiento para estándares de dispositivos de entrada.
4. Construir marcos de prueba y evaluación automatizados.
5. Generar reportes de rendimiento de dispositivos de entrada y recomendaciones.

### Tareas:
- Diseñar interfaz de evaluación de dispositivos de entrada.
- Implementar algoritmos de evaluación ergonómica.
- Crear herramientas de prueba de usabilidad.
- Desarrollar sistema de verificación de cumplimiento.
- Construir análisis de rendimiento y reporte.
- Documentar estándares de dispositivos de entrada y métodos de prueba.

## Salida Esperada:
- Kit de herramientas de evaluación de dispositivos de entrada.
- Sistema de evaluación ergonómica.
- Aplicaciones de prueba de usabilidad.
- Reportes de cumplimiento y recomendaciones.
