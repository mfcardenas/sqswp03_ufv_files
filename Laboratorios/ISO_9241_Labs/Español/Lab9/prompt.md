# Laboratorio 9: Estándares de Dispositivos de Entrada

## Prompt de Regeneración

Crear un kit de herramientas integral de evaluación de estándares de dispositivos de entrada basado en ISO 9241-410 e ISO 9241-411. Incluir:

1. Un enunciado del problema para evaluar ergonomía de dispositivos de entrada, usabilidad y cumplimiento.
2. Código completo HTML, CSS y JavaScript para una interfaz de evaluación interactiva.
3. Herramientas automatizadas de evaluación ergonómica y pruebas de usabilidad.
4. Un script en Python para análisis integral de dispositivos de entrada y verificación de cumplimiento.
5. Documentación de estándares de dispositivos de entrada y metodologías de prueba.

Asegurar que el laboratorio proporcione herramientas prácticas para evaluación profesional de dispositivos de entrada con perspectivas basadas en datos.
