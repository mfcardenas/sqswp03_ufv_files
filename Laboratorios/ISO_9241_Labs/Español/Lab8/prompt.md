# Laboratorio 8: Requisitos de Visualización

## Prompt de Regeneración

Crear un kit de herramientas integral de evaluación de requisitos de visualización basado en ISO 9241-303 e ISO 9241-307. Incluir:

1. Un enunciado del problema para evaluar calidad de pantalla, legibilidad y factores ergonómicos.
2. Código completo HTML, CSS y JavaScript para una interfaz de evaluación interactiva.
3. Herramientas automatizadas de prueba de calidad de pantalla y evaluación de legibilidad.
4. Un script en Python para análisis visual integral y verificación de cumplimiento.
5. Documentación de estándares de visualización y metodologías de prueba.

Asegurar que el laboratorio proporcione herramientas prácticas para evaluación profesional de requisitos de visualización con perspectivas basadas en datos.
