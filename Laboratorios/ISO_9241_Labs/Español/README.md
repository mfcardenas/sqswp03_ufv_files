# Laboratorios ISO 9241 (Español)

Este directorio contiene 10 laboratorios diseñados para enseñar y explorar el estándar ISO 9241 en Español. Cada laboratorio incluye:

1. **Enunciado del Problema**: Una descripción detallada de la tarea o desafío.
2. **Solución**: Una guía paso a paso para resolver el problema.
3. **Prompt de Regeneración**: Un prompt para regenerar la solución dinámicamente.
