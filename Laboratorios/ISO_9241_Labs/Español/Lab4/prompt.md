# Laboratorio 4: Diseño Centrado en el Usuario

## Prompt de Regeneración

Crear un ejercicio de laboratorio integral demostrando el proceso de diseño centrado en el usuario del ISO 9241-210. Incluir:

1. Un enunciado del problema para rediseñar un pago de comercio electrónico usando principios UCD.
2. Personas de usuario, escenarios y análisis de requisitos.
3. Código completo HTML, CSS y JavaScript para un formulario de pago multi-paso.
4. Un script en Python para pruebas automatizadas de usuario y evaluación de usabilidad.
5. Documentación del proceso UCD y mejoras iterativas.
6. Implementación práctica con resultados medibles.

Asegurar que el laboratorio proporcione experiencia práctica con metodologías UCD reales y decisiones de diseño basadas en datos.
