# Laboratorio 4: Diseño Centrado en el Usuario

## Enunciado del Problema

Aplicar el proceso de diseño centrado en el usuario (UCD) del ISO 9241-210 para rediseñar un formulario de pago de comercio electrónico existente. El objetivo es mejorar las tasas de conversión y la satisfacción del usuario a través de diseño y pruebas iterativos.

### Requisitos:
1. Analizar el formulario de pago actual en busca de problemas de usabilidad.
2. Crear personas de usuario y escenarios.
3. Diseñar wireframes y prototipos.
4. Realizar pruebas de usabilidad.
5. Implementar mejoras basadas en retroalimentación del usuario.
6. Crear un script en Python para simular pruebas de usuario y analizar resultados.

### Tareas:
- Documentar problemas de usabilidad actuales.
- Desarrollar personas de usuario y casos de uso.
- Crear prototipos HTML/CSS/JS de diseño mejorado.
- Implementar funcionalidad de pruebas A/B.
- Escribir scripts en Python para pruebas automatizadas de usuario.
- Analizar y documentar mejoras.

## Salida Esperada:
- Personas de usuario y escenarios.
- Múltiples iteraciones de diseño.
- Prototipo funcional con capacidades de prueba.
- Scripts de análisis en Python.
