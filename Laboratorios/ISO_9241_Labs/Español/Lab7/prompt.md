# Laboratorio 7: Métodos de Evaluación

## Prompt de Regeneración

Crear un marco integral de evaluación de usabilidad basado en las directrices del ISO 9241-11. Incluir:

1. Un enunciado del problema para desarrollar herramientas de evaluación multi-método.
2. Código completo HTML, CSS y JavaScript para una interfaz de pruebas de usabilidad.
3. Herramientas automatizadas de evaluación heurística y verificación de accesibilidad.
4. Un script en Python para calcular y analizar métricas de usabilidad.
5. Documentación de metodologías de evaluación y mejores prácticas.

Asegurar que el laboratorio proporcione herramientas prácticas para realizar evaluaciones de usabilidad profesionales con perspectivas basadas en datos.
