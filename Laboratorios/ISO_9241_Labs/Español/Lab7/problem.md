# Laboratorio 7: Métodos de Evaluación

## Enunciado del Problema

Desarrollar un marco integral de evaluación de usabilidad basado en las directrices del ISO 9241-11. Crear herramientas y métodos para realizar pruebas de usuario, evaluación heurística y evaluación automatizada de usabilidad.

### Requisitos:
1. Implementar un marco de evaluación de usabilidad con múltiples métodos.
2. Crear herramientas automatizadas para evaluación heurística y verificación de accesibilidad.
3. Desarrollar un calculador de métricas de usabilidad en Python.
4. Construir una interfaz web para estudios de usuario.
5. Generar reportes integrales de evaluación con perspectivas procesables.

### Tareas:
- Diseñar un marco de evaluación multi-método.
- Implementar herramientas automatizadas de evaluación heurística.
- Crear sistema de cálculo de métricas de usabilidad.
- Desarrollar interfaz de pruebas de usuario y recopilación de datos.
- Construir generación de reportes con recomendaciones.
- Documentar metodología de evaluación y mejores prácticas.

## Salida Esperada:
- Kit de herramientas completo de evaluación de usabilidad.
- Herramientas automatizadas de evaluación.
- Interfaz de pruebas de usuario con análisis de datos.
- Reportes integrales de evaluación.
