# Laboratorio 5: Estándares de Accesibilidad

## Prompt de Regeneración

Crear un ejercicio de laboratorio integral enfocándose en estándares de accesibilidad del ISO 9241 y WCAG 2.1. Incluir:

1. Un enunciado del problema para diseñar una aplicación web accesible.
2. HTML completo con estructura semántica y atributos ARIA.
3. CSS para modo de alto contraste y diseño responsivo.
4. JavaScript para navegación por teclado y soporte de tecnología de asistencia.
5. Un script en Python para pruebas automatizadas de accesibilidad y verificación de cumplimiento.
6. Documentación de directrices WCAG y detalles de implementación.

Asegurar que el laboratorio proporcione experiencia práctica con desafíos de accesibilidad reales y metodologías de prueba.
