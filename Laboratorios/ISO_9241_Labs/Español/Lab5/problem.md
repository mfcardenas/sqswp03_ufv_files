# Laboratorio 5: Evaluación Integral de Usabilidad con Métodos Mixtos

## Enunciado del Problema

Realizarás una evaluación completa de usabilidad aplicando la metodología científica ISO 9241-11 para medir efectividad, eficiencia y satisfacción del diseño de TravelEase desarrollado en laboratorios anteriores. Combinarás métodos cuantitativos y cualitativos para validar empíricamente el cumplimiento de principios de usabilidad y generar recomendaciones priorizadas basadas en evidencia.

### Objetivos:
1. Planificar y ejecutar estudio de usabilidad con usuarios reales (n=9-12)
2. Aplicar métricas objetivas según ISO 9241-11 (efectividad, eficiencia, satisfacción)
3. Realizar triangulación metodológica entre evaluación heurística y testing empírico
4. Analizar datos cuantitativos con rigor estadístico e interpretar feedback cualitativo
5. Priorizar recomendaciones de mejora con análisis de impacto y viabilidad
6. Documentar proceso replicable para organizaciones reales

### Entregables:
- Protocolo de testing de usabilidad completo
- Datos de efectividad, eficiencia y satisfacción con 9-12 usuarios reales
- Análisis estadístico con intervalos de confianza y comparación con benchmarks
- Reporte técnico con recomendaciones priorizadas y estimación de ROI
- Validación cruzada entre métodos heurísticos y empíricos

## Metodología:
- Framework: ISO 9241-11:2018 (Usabilidad: Medición y especificación)
- Participants: 9-12 usuarios representativos de las personas del Lab 1
- Mixed methods: Métricas objetivas + think-aloud protocol + cuestionarios estandarizados
- Análisis: Estadístico descriptivo + inferencial + codificación temática cualitativa
