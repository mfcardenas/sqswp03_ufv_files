# Guía Docente - Laboratorio 5: Evaluación Integral de Usabilidad

## Información del Laboratorio
- **Duración:** 10-12 horas (3h preparación + 3h presencial + 4-6h análisis)
- **Prerequisitos:** Labs 1-4 completados (especialmente Lab 1 personas y Lab 2 diseño)
- **Modalidad:** Híbrida con componente intensivo de testing

## Objetivos Pedagógicos

### Conocimientos
- **ISO 9241-11:2018:** Metodología científica para medir usabilidad
- **Mixed methods research:** Triangulación entre métodos cuantitativos y cualitativos
- **Statistical analysis:** Intervalos de confianza, significancia, benchmarking

### Habilidades
- **Planning:** Diseño de estudios de usabilidad robustos
- **Execution:** Moderación de sesiones de testing con usuarios reales
- **Analysis:** Procesamiento e interpretación de datos de usabilidad
- **Communication:** Reporte ejecutivo con recomendaciones priorizadas

### Competencias
- **Rigor científico:** Aplicación de metodología estándar internacional
- **User advocacy:** Representación de necesidades del usuario con evidencia objetiva
- **Business acumen:** Traducción de insights de UX a impacto de negocio

## Estructura de la Sesión Presencial (3 horas)

### Hora 1: Setup y primeras sesiones
- **0:00-0:15** - Briefing del equipo, asignación de roles, setup equipment
- **0:15-0:45** - Sesiones 1-2 de testing (2 usuarios x 15 min)
- **0:45-1:00** - Break + review inicial de datos

### Hora 2: Sesiones principales  
- **1:00-1:30** - Sesiones 3-4 de testing
- **1:30-2:00** - Sesiones 5-6 de testing

### Hora 3: Cierre y análisis preliminar
- **2:00-2:30** - Sesiones 7-8 de testing (si aplica)
- **2:30-2:45** - Consolidación de datos cuantitativos
- **2:45-3:00** - Planning del análisis post-sesión

## Recursos Necesarios

### Por equipo (2-3 estudiantes)
- 1 computadora con internet estable
- Software de grabación de pantalla
- Cronómetro (app móvil suficiente)
- Formularios impresos (consentimiento, SUS, demográficos)

### Gestión de participantes
- Pool de 12-15 usuarios potenciales por equipo
- Incentivos para participación (definir con institución)
- Espacio para testing sin interrupciones

## Criterios de Evaluación Específicos

### Rigor metodológico (25%)
- **Excelente:** Protocolo ISO 9241-11 aplicado correctamente, sample size justificado
- **Bueno:** Metodología básica correcta, algunas mejoras menores posibles
- **Insuficiente:** Metodología deficiente, conclusiones no soportadas por datos

### Calidad de datos (25%)
- **Excelente:** Datos completos, análisis estadístico apropiado, triangulación efectiva
- **Bueno:** Datos mayormente completos, análisis básico correcto
- **Insuficiente:** Datos incompletos o análisis incorrecto

### Recomendaciones (25%)
- **Excelente:** Priorizadas por evidencia, específicas, ROI estimado
- **Bueno:** Basadas en datos, mayormente específicas
- **Insuficiente:** Genéricas o no basadas en evidencia

### Comunicación (25%)
- **Excelente:** Reporte ejecutivo claro, gráficos informativos
- **Bueno:** Reporte completo y legible
- **Insuficiente:** Reporte confuso o incompleto

## Troubleshooting Común

### "No conseguimos suficientes usuarios"
- **Solución:** Reducir a n=6-8 pero ajustar análisis estadístico
- **Prevención:** Recrutar 15-20 usuarios para garantizar 9-12 shows

### "Los datos no muestran diferencias claras"
- **Normal:** A veces las interfaces están bien diseñadas
- **Enfoque:** Buscar patterns sutiles, diferencias cualitativas, learnings emergentes

### "El prototipo no funciona durante testing"
- **Contingencia:** Backup plan con wireframes estáticos + role-playing
- **Prevención:** Testing técnico exhaustivo pre-sesión

## Extensiones y Variaciones

### Para equipos avanzados
- Análisis de eye-tracking (si equipment disponible)
- Comparación A/B entre 2 diseños alternativos
- Longitudinal study (testing antes y después de período de uso)

### Para contextos con limitaciones
- Remote testing usando herramientas de video conferencia
- Guerrilla testing en espacios públicos de la universidad
- Expert walkthrough como alternativa a user testing
