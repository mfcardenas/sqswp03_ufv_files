# Lab 1: Introduction to Software Quality (Python)

## Challenge Description

In this lab, we will explore the basic concepts of software quality according to the ISO/IEC 25010:2023 standard. You will implement functions that evaluate key aspects of quality.

### Problem 1: Functionality Evaluation
Create a function that takes a list of requirements and an implementation, and evaluates if the implementation meets the requirements. The function should return a compliance percentage.

### Problem 2: Console Usability Improvement
Design a console interface that allows the user to interact with a simple system (e.g., a basic calculator). Evaluate and improve usability based on ISO/IEC 25010 principles.

### Additional Challenges
- Add logging to track requirements compliance.
- Implement input validations to improve robustness.
- Document how your changes improve quality according to the standard.

## Instructions
1. Implement the problems in `problem1.py` and `problem2.py`.
2. Run and test your solutions.
3. Compare with the solutions in `SOLUTION.md`.
