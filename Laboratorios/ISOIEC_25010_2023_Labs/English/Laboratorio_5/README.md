# Lab 5: Efficiency (Python)

## Challenge Description

This lab focuses on software efficiency, optimizing algorithms and measuring performance according to ISO/IEC 25010:2023.

### Problem 1: Inefficient Code Optimization
Take a code with inefficient nested loops and optimize it using comprehensions or better algorithms.

### Problem 2: Performance Measurement
Implement profiling to measure execution times and identify bottlenecks.

### Additional Challenges
- Compare with standard library algorithms.
- Add benchmarks for different input sizes.
- Document efficiency improvements.

## Instructions
1. Implement in `problem1.py` and `problem2.py`.
2. Use cProfile for measurements.
3. Review in `SOLUTION.md`.
