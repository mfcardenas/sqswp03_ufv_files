# Lab 6: Reliability (Java)

## Challenge Description

Focused on reliability, this lab implements mechanisms to handle failures and ensure continuous operation according to ISO/IEC 25010:2023.

### Problem 1: Automatic Retries
Implement a method that retries failed operations a limited number of times.

### Problem 2: Error Recovery
Create a system that handles exceptions and restores the previous state.

### Additional Challenges
- Add detailed failure logging.
- Implement the circuit breaker pattern.
- Test with failure simulations.

## Instructions
1. Implement in `Problem1.java` and `Problem2.java`.
2. Simulate failures and verify recovery.
3. Review in `SOLUTION.md`.
