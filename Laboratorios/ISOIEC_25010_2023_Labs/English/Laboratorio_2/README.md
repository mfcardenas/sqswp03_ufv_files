# Lab 2: Maintainability and Efficiency (Java)

## Challenge Description

This lab focuses on improving software maintainability and efficiency, key aspects of ISO/IEC 25010:2023. You will use design patterns and optimizations.

### Problem 1: Singleton Pattern for Maintainability
Refactor a class that handles configurations to use the Singleton pattern, ensuring a single instance and improving maintainability.

### Problem 2: Search Algorithm Optimization
Implement a linear search algorithm and optimize it to binary search, measuring execution times to demonstrate efficiency improvements.

### Additional Challenges
- Add unit tests to validate the Singleton.
- Compare execution times with different data sizes.
- Document how the pattern improves maintainability according to the standard.

## Instructions
1. Implement in `Problem1.java` and `Problem2.java`.
2. Run and measure performance.
3. Review solutions in `SOLUTION.md`.
