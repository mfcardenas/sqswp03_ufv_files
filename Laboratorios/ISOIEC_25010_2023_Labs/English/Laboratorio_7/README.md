# Lab 7: Usability (Python)

## Challenge Description

This lab explores usability, creating intuitive interfaces and providing feedback according to ISO/IEC 25010:2023.

### Problem 1: Simple User Interface
Create a console interface that guides the user step by step.

### Problem 2: Feedback and Validation
Add validations and help messages to improve the experience.

### Additional Challenges
- Implement interactive menus.
- Add colors or formats for better readability.
- Evaluate usability with heuristics.

## Instructions
1. Implement in `problem1.py` and `problem2.py`.
2. Test with simulated users.
3. Review in `SOLUTION.md`.
