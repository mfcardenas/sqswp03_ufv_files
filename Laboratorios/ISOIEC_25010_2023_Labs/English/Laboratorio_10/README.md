# Lab 10: Complete Quality Evaluation (Java)

## Challenge Description

This final lab integrates all aspects of software quality according to ISO/IEC 25010:2023 in a complete application.

### Problem 1: Application with Multiple Features
Create an application that demonstrates functionality, security, usability, etc.

### Problem 2: Evaluation and Improvements
Evaluate the application using metrics and propose comprehensive improvements.

### Additional Challenges
- Integrate design patterns.
- Add exhaustive tests.
- Document compliance with the standard.

## Instructions
1. Implement in `Problem1.java` and `Problem2.java`.
2. Evaluate and improve.
3. Review in `SOLUTION.md`.
