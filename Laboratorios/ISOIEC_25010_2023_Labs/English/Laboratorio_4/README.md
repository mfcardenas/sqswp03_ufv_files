# Lab 4: Portability and Compatibility (Java)

## Challenge Description

This lab addresses portability and compatibility, ensuring that the software works in various environments according to ISO/IEC 25010:2023.

### Problem 1: Adaptation to Operating Systems
Modify an application to detect the OS and adapt file paths.

### Problem 2: Compatibility between Java Versions
Implement code compatible with Java 8 and 11, using common features.

### Additional Challenges
- Add external configuration for paths.
- Implement cross-platform tests.
- Document compatibility with specific versions.

## Instructions
1. Implement in `Problem1.java` and `Problem2.java`.
2. Test in different environments.
3. Review in `SOLUTION.md`.
