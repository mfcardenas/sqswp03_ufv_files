# Lab 3: Security and Reliability (Python)

## Challenge Description

Focused on security and reliability, this lab demonstrates how to implement security controls and error handling according to ISO/IEC 25010:2023.

### Problem 1: Input Validations for Security
Create a function that validates user inputs to prevent SQL injection and other common attacks.

### Problem 2: Robust Exception Handling
Implement a logging and exception handling system that improves the reliability of an application.

### Additional Challenges
- Add basic encryption for sensitive data.
- Implement automatic retries for failed operations.
- Evaluate reliability with stress tests.

## Instructions
1. Implement in `problem1.py` and `problem2.py`.
2. Test with malicious inputs.
3. Review solutions in `SOLUTION.md`.
