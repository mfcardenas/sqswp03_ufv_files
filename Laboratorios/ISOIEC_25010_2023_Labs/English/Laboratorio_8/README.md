# Lab 8: Compatibility (Java)

## Challenge Description

This lab focuses on compatibility, ensuring that the software works with previous and future versions according to ISO/IEC 25010:2023.

### Problem 1: Compatibility with Old APIs
Implement a class that maintains compatibility with obsolete interfaces.

### Problem 2: Cross-Version Testing
Create tests that verify functionality in different versions of Java.

### Additional Challenges
- Use @Deprecated annotations.
- Implement factories for versions.
- Document compatibility changes.

## Instructions
1. Implement in `Problem1.java` and `Problem2.java`.
2. Test with different JDKs.
3. Review in `SOLUTION.md`.
