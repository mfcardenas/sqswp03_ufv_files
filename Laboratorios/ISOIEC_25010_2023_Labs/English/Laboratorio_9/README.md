# Lab 9: Quality Integration (Python)

## Challenge Description

This lab integrates metrics and tools to evaluate quality during development according to ISO/IEC 25010:2023.

### Problem 1: Unit Tests
Implement unit tests for a function and measure coverage.

### Problem 2: Metrics Analysis
Use tools to analyze cyclomatic complexity and propose improvements.

### Additional Challenges
- Integrate basic CI/CD.
- Generate quality reports.
- Propose refactorings based on metrics.

## Instructions
1. Implement in `problem1.py` and `problem2.py`.
2. Use unittest and radon.
3. Review in `SOLUTION.md`.
