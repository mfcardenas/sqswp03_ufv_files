# Laboratorio 8: Compatibilidad (Java)

## Descripción del Reto

Este laboratorio se enfoca en la compatibilidad, asegurando que el software funcione con versiones anteriores y futuras según ISO/IEC 25010:2023.

### Problema 1: Compatibilidad con APIs Antiguas
Implementa una clase que mantenga compatibilidad con interfaces obsoletas.

### Problema 2: Pruebas Cross-Version
Crea pruebas que verifiquen funcionamiento en diferentes versiones de Java.

### Retos Adicionales
- Usa anotaciones @Deprecated.
- Implementa fábricas para versiones.
- Documenta cambios de compatibilidad.

## Instrucciones
1. Implementa en `Problema1.java` y `Problema2.java`.
2. Prueba con diferentes JDK.
3. Revisa en `SOLUCION.md`.
