# Prompt para Generar Laboratorio 8

Genera un laboratorio sobre compatibilidad según ISO/IEC 25010:2023 usando Java. Incluye:

- Dos problemas: compatibilidad con APIs antiguas y pruebas cross-version.
- Archivos: Problema1.java, Problema2.java, Solucion1.java, Solucion2.java, README.md, SOLUCION.md.
- README.md: Descripción, retos como @Deprecated y fábricas.
- SOLUCION.md: Código con explicaciones.
- Nivel: Avanzado, con conocimientos de versiones y APIs.
- Escalada: De compatibilidad básica a gestión de versiones.

Para estudiantes en evolución de software.
