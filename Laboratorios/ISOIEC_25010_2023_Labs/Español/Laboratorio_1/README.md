# Laboratorio 1: Introducción a la Calidad del Software (Python)

## Descripción del Reto

En este laboratorio, exploraremos los conceptos básicos de calidad del software según el estándar ISO/IEC 25010:2023. Implementarás funciones que evalúen aspectos clave de la calidad.

### Problema 1: Evaluación de Funcionalidad
Crea una función que tome una lista de requisitos y una implementación, y evalúe si la implementación cumple con los requisitos. La función debe devolver un porcentaje de cumplimiento.

### Problema 2: Mejora de Usabilidad en Consola
Diseña una interfaz de consola que permita al usuario interactuar con un sistema simple (ej. una calculadora básica). Evalúa y mejora la usabilidad basándote en principios de ISO/IEC 25010.

### Retos Adicionales
- Añade logging para rastrear el cumplimiento de requisitos.
- Implementa validaciones de entrada para mejorar la robustez.
- Documenta cómo tus cambios mejoran la calidad según el estándar.

## Instrucciones
1. Implementa los problemas en `problema1.py` y `problema2.py`.
2. Ejecuta y prueba tus soluciones.
3. Compara con las soluciones en `SOLUCION.md`.
