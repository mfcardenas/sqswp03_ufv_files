# Prompt para Generar Laboratorio 1

Genera un laboratorio sobre introducción a la calidad del software según ISO/IEC 25010:2023 usando Python. Incluye:

- Dos problemas: uno sobre evaluación de funcionalidad y otro sobre mejora de usabilidad en consola.
- Archivos: problema1.py, problema2.py, solucion1.py, solucion2.py, README.md, SOLUCION.md.
- README.md: Descripción detallada del reto, instrucciones y retos adicionales.
- SOLUCION.md: Código de soluciones con explicaciones.
- Asegúrate de que los problemas no sean simples; incluye validaciones, logging y mejoras de calidad.
- Lenguaje: Python.
- Nivel: Básico, para estudiantes principiantes en ingeniería del software.

Estructura el laboratorio de manera escalonada, comenzando con conceptos básicos y avanzando a aplicaciones prácticas.
