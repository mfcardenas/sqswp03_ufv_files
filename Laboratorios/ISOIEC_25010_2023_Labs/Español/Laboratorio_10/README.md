# Laboratorio 10: Evaluación Completa de la Calidad (Java)

## Descripción del Reto

Este laboratorio final integra todos los aspectos de calidad del software según ISO/IEC 25010:2023 en una aplicación completa.

### Problema 1: Aplicación con Múltiples Características
Crea una aplicación que demuestre funcionalidad, seguridad, usabilidad, etc.

### Problema 2: Evaluación y Mejoras
Evalúa la aplicación usando métricas y propone mejoras integrales.

### Retos Adicionales
- Integra patrones de diseño.
- Añade pruebas exhaustivas.
- Documenta el cumplimiento del estándar.

## Instrucciones
1. Implementa en `Problema1.java` y `Problema2.java`.
2. Evalúa y mejora.
3. Revisa en `SOLUCION.md`.
