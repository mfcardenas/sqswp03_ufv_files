# Laboratorio 6: Fiabilidad (Java)

## Descripción del Reto

Enfocado en la fiabilidad, este laboratorio implementa mecanismos para manejar fallos y asegurar operación continua según ISO/IEC 25010:2023.

### Problema 1: Reintentos Automáticos
Implementa un método que reintente operaciones fallidas un número limitado de veces.

### Problema 2: Recuperación de Errores
Crea un sistema que maneje excepciones y recupere el estado anterior.

### Retos Adicionales
- Añade logging detallado de fallos.
- Implementa circuit breaker pattern.
- Prueba con simulaciones de fallos.

## Instrucciones
1. Implementa en `Problema1.java` y `Problema2.java`.
2. Simula fallos y verifica recuperación.
3. Revisa en `SOLUCION.md`.
