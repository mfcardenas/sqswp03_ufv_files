# Laboratorio 5: Eficiencia (Python)

## Descripción del Reto

Este laboratorio se centra en la eficiencia del software, optimizando algoritmos y midiendo rendimiento según ISO/IEC 25010:2023.

### Problema 1: Optimización de Código Ineficiente
Toma un código con bucles anidados ineficientes y optimízalo usando comprehensions o algoritmos mejores.

### Problema 2: Medición de Rendimiento
Implementa profiling para medir tiempos de ejecución y identificar cuellos de botella.

### Retos Adicionales
- Compara con algoritmos de librerías estándar.
- Añade benchmarks para diferentes tamaños de entrada.
- Documenta mejoras en eficiencia.

## Instrucciones
1. Implementa en `problema1.py` y `problema2.py`.
2. Usa cProfile para mediciones.
3. Revisa en `SOLUCION.md`.
