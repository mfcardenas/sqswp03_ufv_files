# Prompt para Generar Laboratorio 5

Genera un laboratorio sobre eficiencia según ISO/IEC 25010:2023 usando Python. Incluye:

- Dos problemas: optimización de código y medición de rendimiento.
- Archivos: problema1.py, problema2.py, solucion1.py, solucion2.py, README.md, SOLUCION.md.
- README.md: Descripción, retos como benchmarks y documentación.
- SOLUCION.md: Código con explicaciones.
- Nivel: Avanzado, con conocimientos de profiling y optimizaciones.
- Escalada: De optimizaciones simples a análisis de rendimiento.

Para estudiantes interesados en performance.
