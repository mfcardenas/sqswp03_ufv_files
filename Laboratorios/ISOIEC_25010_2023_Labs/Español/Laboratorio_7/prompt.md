# Prompt para Generar Laboratorio 7

Genera un laboratorio sobre usabilidad según ISO/IEC 25010:2023 usando Python. Incluye:

- Dos problemas: interfaz simple y feedback con validación.
- Archivos: problema1.py, problema2.py, solucion1.py, solucion2.py, README.md, SOLUCION.md.
- README.md: Descripción, retos como menús y heurísticas.
- SOLUCION.md: Código con explicaciones.
- Nivel: Intermedio, con conocimientos de input/output.
- Escalada: De interfaces básicas a experiencias avanzadas.

Para estudiantes en diseño de UX básico.
