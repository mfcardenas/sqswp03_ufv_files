# Laboratorio 7: Usabilidad (Python)

## Descripción del Reto

Este laboratorio explora la usabilidad, creando interfaces intuitivas y proporcionando feedback según ISO/IEC 25010:2023.

### Problema 1: Interfaz de Usuario Simple
Crea una interfaz de consola que guíe al usuario paso a paso.

### Problema 2: Feedback y Validación
Añade validaciones y mensajes de ayuda para mejorar la experiencia.

### Retos Adicionales
- Implementa menús interactivos.
- Añade colores o formatos para mejor legibilidad.
- Evalúa usabilidad con heurísticas.

## Instrucciones
1. Implementa en `problema1.py` y `problema2.py`.
2. Prueba con usuarios simulados.
3. Revisa en `SOLUCION.md`.
