# Laboratorio 9: Integración de la Calidad (Python)

## Descripción del Reto

Este laboratorio integra métricas y herramientas para evaluar la calidad durante el desarrollo según ISO/IEC 25010:2023.

### Problema 1: Pruebas Unitarias
Implementa pruebas unitarias para una función y mide cobertura.

### Problema 2: Análisis de Métricas
Usa herramientas para analizar complejidad ciclomática y proponer mejoras.

### Retos Adicionales
- Integra CI/CD básico.
- Genera reportes de calidad.
- Propone refactorizaciones basadas en métricas.

## Instrucciones
1. Implementa en `problema1.py` y `problema2.py`.
2. Usa unittest y radon.
3. Revisa en `SOLUCION.md`.
