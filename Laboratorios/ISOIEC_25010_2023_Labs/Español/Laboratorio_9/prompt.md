# Prompt para Generar Laboratorio 9

Genera un laboratorio sobre integración de la calidad según ISO/IEC 25010:2023 usando Python. Incluye:

- Dos problemas: pruebas unitarias y análisis de métricas.
- Archivos: problema1.py, problema2.py, solucion1.py, solucion2.py, README.md, SOLUCION.md.
- README.md: Descripción, retos como CI/CD y reportes.
- SOLUCION.md: Código con explicaciones.
- Nivel: Experto, con conocimientos de testing y herramientas.
- Escalada: De pruebas básicas a integración completa.

Para estudiantes en DevOps y calidad.
