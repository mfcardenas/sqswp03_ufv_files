# Laboratorio 4: Portabilidad y Compatibilidad (Java)

## Descripción del Reto

Este laboratorio aborda la portabilidad y compatibilidad, asegurando que el software funcione en diversos entornos según ISO/IEC 25010:2023.

### Problema 1: Adaptación a Sistemas Operativos
Modifica una aplicación para detectar el SO y adaptar rutas de archivos.

### Problema 2: Compatibilidad entre Versiones de Java
Implementa código compatible con Java 8 y 11, usando características comunes.

### Retos Adicionales
- Añade configuración externa para rutas.
- Implementa pruebas cross-plataforma.
- Documenta compatibilidad con versiones específicas.

## Instrucciones
1. Implementa en `Problema1.java` y `Problema2.java`.
2. Prueba en diferentes entornos.
3. Revisa en `SOLUCION.md`.
