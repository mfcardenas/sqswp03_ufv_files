# Prompt para Generar Laboratorio 4

Genera un laboratorio sobre portabilidad y compatibilidad según ISO/IEC 25010:2023 usando Java. Incluye:

- Dos problemas: adaptación a SO y compatibilidad entre versiones Java.
- Archivos: Problema1.java, Problema2.java, Solucion1.java, Solucion2.java, README.md, SOLUCION.md.
- README.md: Descripción, retos como configuración externa y pruebas cross-plataforma.
- SOLUCION.md: Código con explicaciones.
- Nivel: Avanzado, con conocimientos de System properties y APIs.
- Escalada: De detección básica a compatibilidad compleja.

Para estudiantes enfocados en despliegues multi-entorno.
