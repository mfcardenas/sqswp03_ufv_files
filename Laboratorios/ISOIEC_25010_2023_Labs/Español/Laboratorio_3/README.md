# Laboratorio 3: Seguridad y Fiabilidad (Python)

## Descripción del Reto

Enfocado en seguridad y fiabilidad, este laboratorio demuestra cómo implementar controles de seguridad y manejo de errores según ISO/IEC 25010:2023.

### Problema 1: Validaciones de Entrada para Seguridad
Crea una función que valide entradas de usuario para prevenir inyecciones SQL y otros ataques comunes.

### Problema 2: Manejo Robusto de Excepciones
Implementa un sistema de logging y manejo de excepciones que mejore la fiabilidad de una aplicación.

### Retos Adicionales
- Añade encriptación básica para datos sensibles.
- Implementa reintentos automáticos para operaciones fallidas.
- Evalúa la fiabilidad con pruebas de estrés.

## Instrucciones
1. Implementa en `problema1.py` y `problema2.py`.
2. Prueba con entradas maliciosas.
3. Revisa soluciones en `SOLUCION.md`.
