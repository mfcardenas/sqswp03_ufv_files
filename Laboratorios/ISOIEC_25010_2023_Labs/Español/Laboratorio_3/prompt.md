# Prompt para Generar Laboratorio 3

Genera un laboratorio sobre seguridad y fiabilidad según ISO/IEC 25010:2023 usando Python. Incluye:

- Dos problemas: validaciones de entrada para seguridad y manejo de excepciones para fiabilidad.
- Archivos: problema1.py, problema2.py, solucion1.py, solucion2.py, README.md, SOLUCION.md.
- README.md: Descripción, retos como encriptación y pruebas de estrés.
- SOLUCION.md: Código con explicaciones.
- Nivel: Intermedio-avanzado, con conocimientos de regex y logging.
- Escalada: De validaciones básicas a sistemas robustos.

Para estudiantes avanzando en prácticas de seguridad.
