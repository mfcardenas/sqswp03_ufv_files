# Prompt para Generar Laboratorio 2

Genera un laboratorio sobre mantenibilidad y eficiencia según ISO/IEC 25010:2023 usando Java. Incluye:

- Dos problemas: uno sobre patrón Singleton para mantenibilidad y otro sobre optimización de algoritmo de búsqueda.
- Archivos: Problema1.java, Problema2.java, Solucion1.java, Solucion2.java, README.md, SOLUCION.md.
- README.md: Descripción detallada, retos adicionales como pruebas unitarias y mediciones.
- SOLUCION.md: Código con explicaciones de mejoras en calidad.
- Nivel: Intermedio, asumiendo conocimientos básicos de Java y patrones.
- Asegúrate de escalar dificultad con optimizaciones y documentación.

Estructura para estudiantes que entienden conceptos básicos y avanzan a aplicaciones prácticas.
