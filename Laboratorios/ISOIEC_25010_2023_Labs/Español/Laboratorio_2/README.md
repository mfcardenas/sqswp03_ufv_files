# Laboratorio 2: Mantenibilidad y Eficiencia (Java)

## Descripción del Reto

Este laboratorio se enfoca en mejorar la mantenibilidad y eficiencia del software, aspectos clave de ISO/IEC 25010:2023. Utilizarás patrones de diseño y optimizaciones.

### Problema 1: Patrón Singleton para Mantenibilidad
Refactoriza una clase que maneje configuraciones para usar el patrón Singleton, asegurando una única instancia y mejorando la mantenibilidad.

### Problema 2: Optimización de Algoritmo de Búsqueda
Implementa un algoritmo de búsqueda lineal y optimízalo a binaria, midiendo tiempos de ejecución para demostrar mejoras en eficiencia.

### Retos Adicionales
- Añade pruebas unitarias para validar el Singleton.
- Compara tiempos de ejecución con diferentes tamaños de datos.
- Documenta cómo el patrón mejora la mantenibilidad según el estándar.

## Instrucciones
1. Implementa en `Problema1.java` y `Problema2.java`.
2. Ejecuta y mide rendimiento.
3. Revisa soluciones en `SOLUCION.md`.
