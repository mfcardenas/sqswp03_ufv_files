# Laboratorio 2: Técnicas de Elicitación de Requisitos - Prompt

## Objetivos de Aprendizaje
Al finalizar este laboratorio, los estudiantes podrán:

1. **Aplicar múltiples técnicas de elicitación** incluyendo entrevistas, cuestionarios, observación y análisis de documentos
2. **Diseñar instrumentos efectivos de elicitación** para diferentes tipos de interesados y contextos
3. **Analizar y sintetizar requisitos** de múltiples fuentes utilizando métodos sistemáticos
4. **Identificar y resolver conflictos** entre requisitos de diferentes técnicas de elicitación
5. **Evaluar la efectividad de las técnicas de elicitación** y seleccionar métodos apropiados para diferentes escenarios
6. **Crear planes comprehensivos de elicitación** que combinen múltiples técnicas efectivamente

## Escenario: Plataforma de Comercio Electrónico

Eres un ingeniero de requisitos trabajando para una empresa de comercio electrónico que desea desarrollar un nuevo programa de lealtad de clientes. El sistema necesita integrarse con su plataforma existente de comercio electrónico y proporcionar recompensas personalizadas, elementos de gamificación y análisis para inteligencia de negocio.

Tu tarea es elicitar requisitos de múltiples interesados utilizando varias técnicas y sintetizarlos en una especificación coherente de requisitos.

## Tareas

### Tarea 1: Planificación y Ejecución de Entrevistas (30 puntos)
Diseñar y ejecutar entrevistas estructuradas con los siguientes interesados:
- **Gerente de Producto**: Enfoque en objetivos de negocio y requisitos estratégicos
- **Gerente de Marketing**: Enfoque en engagement de clientes y requisitos promocionales
- **Gerente de TI**: Enfoque en restricciones técnicas y requisitos de integración
- **Representante de Servicio al Cliente**: Enfoque en requisitos operativos y puntos de dolor del usuario

**Entregables:**
- Guías de entrevista para cada tipo de interesado
- Transcripciones de entrevistas o resúmenes
- Análisis de requisitos clave identificados
- Matriz de prioridades de interesados

### Tarea 2: Diseño y Análisis de Cuestionarios (25 puntos)
Crear y analizar cuestionarios para:
- **Clientes actuales** (n=50): Patrones de uso, preferencias, puntos de dolor
- **Clientes potenciales** (n=30): Expectativas, prioridades de características
- **Socios de negocio** (n=10): Requisitos de integración, necesidades de compartir datos

**Entregables:**
- Plantillas de cuestionarios con diferentes tipos de preguntas
- Análisis de respuestas con resúmenes estadísticos
- Perspectivas clave y patrones identificados
- Recomendaciones basadas en datos cuantitativos

### Tarea 3: Observación e Investigación Contextual (20 puntos)
Realizar sesiones de observación para:
- **Proceso de compra del cliente** observación
- **Interacciones de servicio al cliente** análisis
- **Flujo de trabajo de empleados** en gestión de programa de lealtad
- **Patrones de uso de aplicación móvil**

**Entregables:**
- Protocolos de observación y listas de verificación
- Registros de actividad y diagramas de flujo de trabajo
- Identificación de cuellos de botella y recomendaciones
- Hallazgos de investigación contextual

### Tarea 4: Análisis de Documentos (15 puntos)
Analizar documentación existente:
- **Documentos de requisitos de negocio**
- **Especificaciones técnicas**
- **Manuales de usuario y documentación de ayuda**
- **Reportes de análisis de competencia**
- **Documentos de cumplimiento regulatorio**

**Entregables:**
- Matriz de extracción de requisitos
- Reporte de análisis de brechas
- Análisis de referencias cruzadas de documentos
- Identificación de requisitos faltantes

### Tarea 5: Integración de Técnicas y Síntesis (10 puntos)
Combinar hallazgos de todas las técnicas:
- **Consolidación de requisitos** de múltiples fuentes
- **Identificación y resolución de conflictos**
- **Matriz de priorización de requisitos**
- **Establecimiento de trazabilidad** entre técnicas

**Entregables:**
- Especificación consolidada de requisitos
- Registro de resolución de conflictos
- Matriz de trazabilidad de requisitos
- Reporte de recomendaciones finales

## Criterios de Evaluación

### Implementación Técnica (40%)
- **Calidad del Código**: Bien estructurado, documentado y eficiente
- **Funcionalidad**: Todas las características funcionan como especificado
- **Manejo de Errores**: Validación apropiada y gestión de errores
- **Interfaz de Usuario**: Intuitiva y diseño profesional

### Prácticas de Ingeniería de Requisitos (35%)
- **Selección de Técnica**: Métodos apropiados para diferentes contextos
- **Análisis de Interesados**: Cobertura comprehensiva de tipos de interesados
- **Calidad de Requisitos**: Requisitos claros, completos, consistentes y testeables
- **Documentación**: Profesional y bien organizada

### Análisis y Síntesis (25%)
- **Análisis de Datos**: Uso efectivo de análisis estadístico y cualitativo
- **Calidad de Síntesis**: Integración lógica de múltiples fuentes de datos
- **Resolución de Conflictos**: Enfoque sistemático para resolver contradicciones
- **Recomendaciones**: Perspectivas accionables basadas en hallazgos

## Recursos Requeridos
- Acceso a interesados para entrevistas
- Herramientas de distribución de encuestas
- Equipo de grabación para observaciones
- Software de análisis de documentos
- Herramientas de análisis estadístico
- Software de gestión de requisitos

## Métricas de Éxito
- **Cobertura de Interesados**: 80% de interesados identificados entrevistados
- **Tasa de Respuesta**: 60% de tasa de respuesta en cuestionarios
- **Requisitos Identificados**: Mínimo 50 requisitos funcionales
- **Conflictos Resueltos**: Todos los conflictos mayores documentados y resueltos
- **Integración de Técnicas**: Requisitos trazados a múltiples fuentes

## Actividades de Extensión
1. **Prototipado Avanzado**: Crear prototipos interactivos para validación
2. **Integración de Machine Learning**: Usar NLP para extracción automática de requisitos
3. **Analytics en Tiempo Real**: Implementar dashboard para monitoreo de elicitación en vivo
4. **Elicitación Móvil**: Desarrollar app móvil para captura de requisitos sobre la marcha

## Consideraciones Éticas
- **Protección de Privacidad**: Asegurar confidencialidad de datos de interesados
- **Consentimiento Informado**: Obtener permiso para grabaciones y observaciones
- **Mitigación de Sesgos**: Usar muestras diversas de interesados
- **Seguridad de Datos**: Almacenamiento seguro de información sensible

## Requisitos de Entrega
- Todos los archivos de código con documentación apropiada
- Reportes de análisis en formato PDF
- Dashboard interactivo accesible vía navegador web
- Documento de especificación de requisitos
- Presentación de hallazgos (10 minutos)

Recuerda: Este laboratorio enfatiza la aplicación práctica de técnicas de elicitación de requisitos. Enfócate en crear herramientas y procesos que puedan ser reutilizados en proyectos del mundo real, no solo conocimiento teórico.
