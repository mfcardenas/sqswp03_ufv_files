ISO/IEC/IEEE 29148 - Ingeniería de Requisitos

🏠 Volver al Índice 🇬🇧 English Version

Esta serie de laboratorios explora los conceptos, procesos y artefactos de la Ingeniería de Requisitos según el estándar ISO/IEC/IEEE 29148.

Lab 1: Introduction to Requirements Engineering

Problem Statement

Develop a comprehensive introduction to Requirements Engineering according to ISO/IEC/IEEE 29148 standard. Create an interactive system that demonstrates the fundamental concepts, processes, and artifacts of requirements engineering.

Requirements:

  • Define requirements engineering concepts and terminology.
  • Explain the requirements engineering process according to ISO/IEC/IEEE 29148.
  • Create interactive examples of requirements artifacts.
  • Develop a requirements classification system.
  • Build a stakeholder analysis tool.

Tasks:

  • Define requirements engineering fundamentals.
  • Explain ISO/IEC/IEEE 29148 process framework.
  • Create requirements artifact templates.
  • Develop stakeholder identification and analysis tools.
  • Build requirements quality assessment tools.

Expected Output:

  • Interactive requirements engineering introduction.
  • Requirements artifact templates and examples.
  • Stakeholder analysis tools.
  • Requirements quality assessment framework.
Lab 2: Requirements Elicitation Techniques

Learning Objectives

By the end of this laboratory, students will be able to understand and apply various requirements elicitation techniques like structured interviews, questionnaires, observation, and prototyping.

Tasks:

  • Task 1: Interactive Elicitation Techniques Dashboard: Create a web app demonstrating techniques like an Interview Management System, Questionnaire Builder, Observation Tools, and a Prototyping Interface.
  • Task 2: Python Elicitation Analysis Tool: Develop a Python system for analyzing data from interviews and questionnaires, processing observation data, and integrating findings from multiple techniques.
  • Task 3: Elicitation Process Application: Apply the learned techniques to a real-world scenario, including stakeholder analysis, elicitation execution, and requirements synthesis.
Lab 3: Requirements Analysis & Modeling

Scenario: Smart Home Automation System

Analyze requirements for a smart home automation system integrating lighting, security, climate control, and entertainment. Fix issues in provided requirements and create proper models.

Tasks:

  • Task 1: Fix Python Analysis Tool: Resolve bugs in requirement loading, ambiguity detection, completeness checking, consistency checking, categorization, dependency identification, prioritization, and model generation.
  • Task 2: Fix Modeling Dashboard: Add navigation functionality, implement analysis display, create modeling canvases, add validation tools, and improve UI.
  • Task 3: Create Sample Data & Testing: Create sample requirements, add comprehensive tests, generate sample models, and add error handling.
  • Task 4: Documentation & Reporting: Add comprehensive comments, create usage examples, generate analysis reports, and add model visualization.
Lab 4: Requirements Specification

Objective

Master requirements specification by creating comprehensive, unambiguous requirement documents using industry-standard formats and templates that meet ISO/IEC/IEEE 29148 standards.

Problem

Current specifications have poor structure, lack traceability, inconsistent formatting, missing validation criteria, and no version control. You must create a comprehensive requirements specification system.

Key Features to Implement:

  • Structured SRS documents with proper sections and formatting
  • Multiple specification formats (textual, tabular, graphical)
  • Traceability matrices linking requirements to design and test
  • Specifications validation against quality standards
  • Requirement baselines with version control
  • Interactive specification viewer for stakeholders
Lab 5: Requirements Validation

Introduction

Work on requirements validation following ISO/IEC/IEEE 29148. Fix code containing intentional bugs to create a complete requirements validation system.

Tasks:

  • Task 1: Fix Validation Engine: Initialize validation rules, implement comprehensive validation methods (completeness, consistency, feasibility, testability), generate test cases automatically, implement acceptance testing framework, and add ISO/IEC/IEEE 29148 compliance checking.
  • Task 2: Complete Validation Dashboard: Create comprehensive validation metrics display, implement test case management interface, add acceptance testing controls, create compliance reporting, and add interactive validation charts.
  • Task 3: Create Supporting Files: Complete CSS styling, functional JavaScript, sample requirements data, and test suite.
Lab 6: Requirements Management

Problem Statement

Implement a comprehensive requirements management system following ISO/IEC/IEEE 29148 standards. Handle the complete lifecycle from creation to retirement, including version control, change management, traceability, and stakeholder collaboration.

Core Functionality:

  • Requirements Repository: Centralized storage with version control
  • Change Management: Formal process for requirement modifications
  • Traceability Matrix: Bidirectional traceability between requirements
  • Stakeholder Management: User roles and permissions
  • Audit Trail: Complete history of all changes
  • Reporting: Comprehensive reports and dashboards
