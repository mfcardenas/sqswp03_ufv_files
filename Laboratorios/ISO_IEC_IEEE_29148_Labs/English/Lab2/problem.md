# Lab 2: Requirements Elicitation Techniques

## Learning Objectives
By the end of this laboratory, students will be able to:

1. Understand different requirements elicitation techniques
2. Apply structured interviews for requirements gathering
3. Create and conduct effective questionnaires
4. Perform observation and document analysis
5. Use prototyping for requirements validation
6. Combine multiple elicitation techniques
7. Document and prioritize elicited requirements

## Prerequisites
- Basic understanding of requirements engineering concepts
- Familiarity with HTML, CSS, and JavaScript
- Python programming knowledge
- Text editor or IDE for code development

## Materials Needed
- Computer with internet access
- Web browser (Chrome, Firefox, or Edge recommended)
- Python 3.x installed
- Text editor (VS Code, Sublime Text, or similar)

## Laboratory Tasks

### Task 1: Interactive Elicitation Techniques Dashboard (35 points)
Create an interactive web application demonstrating various elicitation techniques:

1. **Interview Management System**: Implement:
   - Interview planning and scheduling
   - Question generation based on stakeholder type
   - Response recording and categorization
   - Follow-up question generation

2. **Questionnaire Builder**: Develop:
   - Dynamic questionnaire creation
   - Multiple question types (open-ended, closed-ended, rating scales)
   - Survey distribution and collection
   - Response analysis and visualization

3. **Observation Tools**: Create:
   - Activity logging system
   - Workflow recording interface
   - Time-motion studies
   - Contextual inquiry tools

4. **Document Analysis System**: Implement:
   - Document upload and parsing
   - Requirements extraction from documents
   - Gap analysis between documents
   - Requirements consolidation

5. **Prototyping Interface**: Develop:
   - Wireframe creation tools
   - Interactive prototype builder
   - User feedback collection
   - Prototype iteration tracking

**Deliverables**:
- `elicitation_dashboard.html` - Main dashboard file
- `elicitation_styles.css` - Styling for the dashboard
- `elicitation_scripts.js` - Interactive functionality
- Screenshots of working elicitation tools

### Task 2: Python Elicitation Analysis Tool (40 points)
Develop a comprehensive Python system for elicitation data analysis:

1. **Interview Analysis**: Implement methods for:
   - Interview transcription processing
   - Theme extraction and coding
   - Sentiment analysis of responses
   - Requirements identification from interviews

2. **Questionnaire Analysis**: Create functionality for:
   - Statistical analysis of survey responses
   - Cross-tabulation and correlation analysis
   - Open-ended response categorization
   - Survey reliability assessment

3. **Observation Data Processing**: Develop:
   - Activity pattern recognition
   - Workflow modeling from observations
   - Bottleneck identification
   - Process optimization recommendations

4. **Multi-Technique Integration**: Implement:
   - Data consolidation from multiple sources
   - Conflict resolution between techniques
   - Requirements prioritization
   - Stakeholder consensus building

**Deliverables**:
- `elicitation_analyzer.py` - Complete Python analysis system
- Sample datasets for different elicitation techniques
- Analysis reports and visualizations
- Unit tests for key functionality

### Task 3: Elicitation Process Application (25 points)
Apply elicitation techniques to a real-world scenario:

1. **Scenario Selection**: Choose from:
   - Healthcare patient management system
   - University course registration system
   - Retail inventory management system
   - Manufacturing quality control system

2. **Stakeholder Analysis**: For your chosen scenario:
   - Identify all stakeholder groups
   - Determine appropriate elicitation techniques per group
   - Create stakeholder communication plan

3. **Elicitation Execution**: Conduct:
   - At least 3 different elicitation techniques
   - Document the process and findings
   - Record stakeholder feedback

4. **Requirements Synthesis**: Develop:
   - Consolidated requirements list
   - Requirements traceability to sources
   - Validation with stakeholders
   - Prioritized requirements backlog

**Deliverables**:
- `elicitation_process.md` - Complete process documentation
- Raw elicitation data and transcripts
- Consolidated requirements specification
- Stakeholder feedback summary
