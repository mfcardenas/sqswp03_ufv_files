# 🎯 ISO Laboratory - Bilingual Technical Decisions Simulator

## 📋 Project Overview

This repository contains a complete bilingual implementation of the ISO Laboratory, an educational simulator that teaches software engineering through real technical decisions that impact ISO 25010 quality metrics.

## 🌍 Available Languages

- **English (Default)**: Complete simulator with all features
- **Spanish (Original)**: Full functionality in Spanish

## 🚀 Getting Started

### Quick Access
1. Open `iso-index.html` to choose your language
2. Select English or Spanish version
3. Start making technical decisions in realistic project scenarios

### Direct Access
- **English**: Open `iso-real-en.html`
- **Spanish**: Open `iso-real.html`

## 🎮 Game Features

### Core Simulator
- **4 Project Types**: E-commerce, Hospital, FinTech, Social Network

## 📊 Quality Metrics (ISO 25010)

The simulator tracks 8 quality characteristics:

1. **Functional Suitability**: How well the software provides functions that meet stated needs
2. **Performance Efficiency**: Performance relative to the amount of resources used
3. **Compatibility**: Ability to perform required functions while sharing environments
4. **Usability**: Ease of use and learnability for users
5. **Reliability**: Ability to perform specified functions under specified conditions
6. **Security**: Protection of information and data access control
7. **Maintainability**: Ease of maintenance and modification
8. **Portability**: Ease of transfer from one environment to another
