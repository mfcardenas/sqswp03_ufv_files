# 🎯 LABORATORIO ISO - SIMULADOR REAL DE DECISIONES TÉCNICAS

## 🚀 **¿QUÉ ES ESTE JUEGO REALMENTE?**

No es una "aplicación bonita sin contenido". Es un **SIMULADOR EDUCATIVO REAL** que implementa las mecánicas exactas de los estándares ISO en decisiones de ingeniería de software.

## 🎮 **MECÁNICAS DE JUEGO REALES IMPLEMENTADAS**

### 1. **SIMULADOR DE DECISIONES TÉCNICAS**
- **Arquitectura**: Monolítica vs Microservicios vs Serverless
- **Base de Datos**: SQL vs NoSQL vs Híbrida  
- **Testing**: Manual vs Automatizado vs Crítico
- **Seguridad**: Básica vs Avanzada vs Extrema
- **UI/UX**: Funcional vs Profesional vs Innovador

**Cada decisión impacta métricas ISO 25010 REALES:**
- ✅ Funcionalidad (Functional Suitability)
- ✅ Eficiencia (Performance Efficiency) 
- ✅ Compatibilidad (Compatibility)
- ✅ Usabilidad (Usability)
- ✅ Confiabilidad (Reliability)
- ✅ Seguridad (Security)
- ✅ Mantenibilidad (Maintainability)
- ✅ Portabilidad (Portability)

### 2. **GESTIÓN DE RECURSOS REALISTA**
- **Presupuesto limitado**: Cada decisión cuesta dinero real
- **Tiempo limitado**: Decisiones complejas requieren más tiempo
- **Trade-offs reales**: No puedes maximizar todo con recursos limitados

### 3. **EVENTOS ALEATORIOS COMO EN PROYECTOS REALES**
- Cambios de requisitos del cliente
- Vulnerabilidades de seguridad descubiertas
- Desarrolladores senior que se van
- Nuevas regulaciones que cumplir

### 4. **OBJETIVOS ISO ESPECÍFICOS POR PROYECTO**
- **E-commerce**: Usabilidad 90%, Seguridad 95%, Eficiencia 80%
- **Hospital**: Confiabilidad 98%, Seguridad 99%, Funcionalidad 95%
- **Finanzas**: Eficiencia 95%, Seguridad 99%, Confiabilidad 95%
- **Social**: Usabilidad 95%, Eficiencia 85%, Escalabilidad 90%

## 📊 **SISTEMA DE EVALUACIÓN CIENTÍFICO**

### **Fórmula de Puntuación Real:**
```javascript
// Por cada métrica ISO
if (metricaActual >= objetivoMinimo) {
    puntos += (metricaActual - objetivo) * 2 + objetivo;
} else {
    puntos += metricaActual * 0.5; // Penalización
}

// Bonificación por eficiencia
if (presupuestoRestante > 0) puntos += presupuestoRestante * 0.01;
if (tiempoRestante > 0) puntos += tiempoRestante * 10;
```

### **Condiciones de Éxito/Fracaso:**
- **🏆 Éxito Excepcional**: 90%+ objetivos cumplidos
- **✅ Éxito**: 70%+ objetivos cumplidos  
- **⚠️ Éxito Parcial**: 50%+ objetivos cumplidos
- **❌ Fracaso**: <50% objetivos cumplidos
