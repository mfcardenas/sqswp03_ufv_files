
# Consulting Lab ISO  
Entrenador Profesional en Ingeniería de Software Basado en ISO 29148, ISO 25010 e ISO 9241

---

## 📌 ¿Qué es Consulting Lab ISO?

**Consulting Lab ISO** es un simulador avanzado diseñado para formar a estudiantes y profesionales junior en el análisis, diseño y evaluación de proyectos de software utilizando los estándares internacionales:

- **ISO/IEC/IEEE 29148** (Requisitos de Software)
- **ISO/IEC 25010** (Calidad del Producto Software)
- **ISO 9241** (Ergonomía y experiencia de usuario)

A diferencia de un cuestionario tradicional, Consulting Lab ISO no evalúa memorización. Coloca al usuario en una **simulación profesional**, donde asume el rol de **consultor** frente a un cliente que expone un proyecto realista con retos, urgencias, limitaciones y riesgos.

---

## 🎯 Objetivo del Simulador

Ofrecer una experiencia inmersiva donde el estudiante:

- Analiza información incompleta o ambigua.  
- Formula preguntas como ocurriría en una primera entrevista con un cliente real.  
- Identifica lagunas, riesgos y dependencias.  
- Estructura requisitos usando criterios de calidad y estándares internacionales.  
- Toma decisiones técnicas justificadas.  
- Practica habilidades clave para entrevistas técnicas y roles de consultoría.  

---

## 🧠 ¿Cómo funciona?

El simulador guía la sesión en **dos fases progresivas**.

### **Fase 1: Onboarding Visual y Suave**

- El usuario selecciona el idioma (inglés o español).
- El GPT presenta un proyecto de forma visual y narrativa.
- Se introducen actores, riesgos y necesidades mediante escenas y microflujos.
- El usuario debe tomar notas, igual que en una reunión profesional.
- Se plantea una microtarea simple (por ejemplo, identificar información faltante).

Ejemplo de microrepresentaciones visuales:



👤 Usuario: Paciente
📱 Interacción: Portal de citas
⚙️ Backend: Motor de agenda
🖥️ Vista interna: Panel operativo


[Scene]
El cliente observa un tablero con tiempos de espera irregulares
[/Scene]



---

### **Fase 2: Ciclo de Vida Completo**

Una vez asentado el contexto, Consulting Lab ISO conduce al usuario por un ciclo de vida verdadero:

- Análisis del problema  
- Necesidades y contexto de uso (ISO 9241)  
- Definición estructurada de requisitos (ISO 29148)  
- Atributos de calidad (ISO 25010)  
- Diseño conceptual y usabilidad  
- Arquitectura preliminar  
- Riesgos y restricciones técnicas  
- Validación y criterios de aceptación  

El estudiante debe tomar decisiones, justificar y avanzar.  
El GPT guía, ofrece pistas discretas y plantea situaciones reales, sin resolver.

## 🧩 Estilo Visual y Dinámico

Consulting Lab ISO utiliza un lenguaje visual limpio, elegante y sin cajas ASCII, evitando saturación.  
Cada mensaje incluye elementos visuales como:

- Iconos semánticos  
- Micro escenas  
- Flujos con iconos  
- Micro UI estilizada  
- Pseudogifs dinámicos  

Ejemplo:

```

GIF
🔄 Analizando requisitos
🔍 Detectando ambigüedades
📌 Preparando próxima decisión
End GIF

```

---

## 🧭 Control Estricto del Contexto

- El estudiante no puede usar el chat para temas ajenos.
- Si se desvía, el GPT lo reconduce sin perder el hilo.  
- No se ofrecen elogios ni juicios personalizados.  
- El tono es técnico, neutral y profesional.  
- El simulador sugiere abrir un nuevo chat si se quiere iniciar otro caso.

---

## 🎓 Orientación a Entrevistas Técnicas

Durante la simulación, el usuario recibe:

- Pistas estratégicas para mejorar razonamiento técnico.  
- Preguntas tipo que podría recibir en una entrevista profesional.  
- Espacios para plantear preguntas profundas al profesor o mentor.  

---

## 📄 Informe Final

Al terminar el ciclo, Consulting Lab ISO genera un informe profesional que resume:

- Decisiones tomadas  
- Riesgos tratados  
- Requisitos generados  
- Calidad evaluada  
- Puntos críticos  
- Recomendaciones para versiones futuras  

Sin elogios y sin evaluaciones subjetivas.

---

## 🧭 ¿Para qué sirve?

Consulting Lab ISO es ideal para:

- Estudiantes de ingeniería de software  
- Cursos universitarios sobre requisitos, calidad o UX  
- Preparación para entrevistas técnicas  
- Formación interna en empresas  
- Talleres de normalización o diseño centrado en el usuario
